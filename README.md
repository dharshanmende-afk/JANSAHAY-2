## 🌟 Executive Overview
**JANSAAHAY (जनसहाय - Public Assistance)** is an all-in-one student financial aid ecosystem built to bridge the awareness gap in scholarship discovery. Across India and worldwide, thousands of crores in scholarship funds remain unutilized or rejected due to minor paperwork errors, missed deadlines, or lack of clear step-by-step guidance.

**JANSAAHAY 2.0** provides:
1. **Full Scope Clarity:** Every scholarship details tuition fee coverage, maintenance allowances, laptop/book grants, and direct benefit transfer (DBT) rules across 35+ authentic national, state, and global schemes.
2. **Smart Eligibility Matcher:** An interactive 5-factor evaluation engine that matches students based on Course Level, Caste Category, Annual Income, Previous Marks, Gender, and Special Quotas.
3. **PFMS Name & Demographic Mismatch Detector:** Real-time token matching checking Class 10th Marksheet, Aadhaar, and Bank passbook spellings with ready-to-print Bank KYC correction request letters.
4. **Official Bonafide Certificate Generator:** Standardized, verified Bonafide format generator for NSP and State portals with AISHE code and principal signature block.
5. **Scholarship Comparison Matrix:** Side-by-side comparison of up to 3 scholarships.
6. **Multi-lingual Vernacular Support:** Live language switcher supporting English, Hindi (हिंदी), Telugu (తెలుగు), Tamil (தமிழ்), Kannada (ಕನ್ನಡ), and Marathi (मराठी).
7. **Document Readiness Tool:** Pre-application audit checking Aadhaar-mobile linkage, NPCI bank account seeding, Tehsildar income certificates, and Bonafide certificates.
8. **Personal Application Tracker:** Offline-first dashboard to monitor deadlines, application stages, and college verification milestones.
9. **Saahay Mitra (सहाय मित्र) Counselor:** Interactive advisory widget addressing student dilemmas in real-time.

## 📱 Responsive & Mobile-First Design
- **Smart Mobile Layout:** Dedicated mobile drawer, touch-friendly tap targets, and horizontal scrollable category pills.
- **Laptop / Desktop Layout:** Full wide-screen dashboard, side-by-side eligibility comparison, and interactive modals.
- **Print / PDF Summary:** 1-click printable scholarship briefs for students to bring to Cyber Cafes / CSC centers / College desks.
- **Dark Mode Support:** Auto-detects system theme with one-click manual toggle.

## 🛠️ Tech Stack
- **Framework:** React 18 with Vite

## 💻 How to Run Locally

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Execution
```bash
# 1. Clone repository
git clone https://github.com/dharshanmende-afk/JANSAHAY-2.git
cd JANSAHAY-2

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Open in browser (accessible on mobile on the same Wi-Fi)
http://localhost:3000
```

### Windows 1-Click Launch
Double-click `start.bat` in the root folder.
